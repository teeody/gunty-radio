# Gunty Radio

Old-school Winamp-style web radio player with live station search, filters, favorites-style quick play, and resilient stream fallback.

## Features
- Winamp-inspired UI with Gunty Radio branding
- Live station search and category filters
- Yacht Rock and Portugal categories
- Stream fallback URLs for selected stations
- Report-a-problem link (top and bottom)

## Run
Open `index.html` in a browser, or serve the folder with any static web server.
